# IS218 Career Research — Portfolio Plan

**Live site:** https://anabhayana.github.io/is218-career-research/  
**Planning record / SPEC:** [PORTFOLIO_RECORD.md](PORTFOLIO_RECORD.md)

This repository is for the **career research and planning stage**, not the finished professional portfolio. The site compares three original employer roles and two career directions; the record explains audience, design alternatives, user stories, architecture, testing and next steps.

## Editing and preview

1. Edit `index.html` for the public page (plain HTML and CSS, no build step).
2. Edit `PORTFOLIO_RECORD.md` to document decisions, source dates, checks and feedback.
3. Commit to `main`. GitHub Pages should redeploy; verify the public page after publishing.
4. For local preview, open `index.html` in a browser, or run `python -m http.server 8000` in the repository folder and visit http://localhost:8000/.
